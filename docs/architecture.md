# 架构说明

## 整体架构

本教程基于华为云 CCE 展示 Kubernetes 的完整操作流程。

## 核心组件

### 1. CCE 集群

- **Master Nodes**：管理节点，由 CCE 自动管理
- **Worker Nodes**：工作节点，可按需扩展
- **网络**：VPC 隔离，弹性 IP

### 2. 存储层

- **EVS**：块存储，用于持久化数据
- **OBS**：对象存储，用于文件/镜像
- **SFS**：文件存储

### 3. 网络层

- **VPC**：虚拟私有云
- **ELB**：弹性负载均衡
- **Security Group**：安全组

### 4. 监控层

- **CES**：云监控服务
- **LTS**：日志服务

## 技术栈

| 组件 | 华为云服务 |
|------|-----------|
| 容器编排 | CCE |
| 存储 | EVS / OBS |
| 网络 | VPC / ELB |
| 监控 | CES / LTS |
| 镜像仓库 | SWR |
| 数据库 | RDS / RDS MySQL |
